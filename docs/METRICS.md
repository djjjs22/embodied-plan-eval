# 指标体系

每个指标四段：定义、计算方式、口径、已知局限。**局限那一栏最重要**，写出来说明你知道尺子的边界在哪。

## 主指标 vs 辅助指标

**主指标**就是项目用来回答「模型行不行」的那一个，**必须能从主指标里得出结论**。本项目的主指标只有一个：**任务成功率**。它是终局判定，覆盖最广，可解释性最强。

| 层 | 指标 | 主/辅 | 为什么 |
| --- | --- | --- | --- |
| 能力 | **任务成功率** | **主** | 终局判定，一个数说清行不行 |
| 能力 | 子目标完成率 | 辅 | 主指标的细节补充，定位到哪个子项失败 |
| 能力 | 序列精确匹配率 | 辅 | 太严，多解法的任务会误判 |
| 能力 | 归一化编辑距离 | 辅 | 顺序敏感，等价路径会得高分 |
| 可靠性 | 前置条件违反率 | **辅但独特** | 项目独有的物理常识指标，但不能替代主指标 |
| 可靠性 | pass^k | 辅 | 测稳定性，主指标看不准的部分由它补 |
| 效率 | 平均动作步数 | 辅 | 与 gold 对比会失真（gold 不是最短） |
| 效率 | 单条调用成本 | 辅 | 运维数据，不影响模型评价 |

**主指标只有一条的好处**：报告结论不打架。**坏处**：光看一个数会漏掉细节，所以辅指标必须配合。

**辅指标失真时的处理原则**：发现某条辅指标不再可靠，就在它旁边明示边界，**不要修到它可信为止**——那条边界本身就是项目的资产。比如「路径效率」已知 gold 不是最短、模型那 94% 的「更短」也是靠少写移动动作，所以这个指标干脆不报，**比硬修更有价值**。

## 能力层

### 任务成功率

- 定义：符号执行后全部目标条件达成，且全程无前置条件违反
- 计算：`count(目标达成 且 违反数=0) / count(样本)`
- 口径：目标条件来自 `pddl_params`；一旦出现前置条件违反即中止后续推演
- 局限：只验证高层规划，**不代表机器人真能执行成功**。真实的抓取失败、视觉误检都不在这个指标里

### 子目标完成率

- 定义：达成目标条件中必需子项的平均比例
- 计算：对每条样本算 `已达成子项 / 必需子项`，再对样本取平均
- 口径：子项包括「放置在目标容器」「已切片」「已切换开关」等
- 局限：粒度较粗，部分完成的程度区分不出来；不同任务类型的子项数不同，横向可比性有限

### 序列精确匹配率

- 定义：模型输出与 gold 动作序列完全一致
- 计算：`count(序列相等) / count(样本)`
- 口径：逐元素比较，参数名归一化后比对
- 局限：**过于严格**。存在多条等价路径时，语义正确的方案会被判错。这个指标只作参考，不能当主指标

### 归一化编辑距离

- 定义：转成 gold 序列所需的最少编辑次数，除以两者最大长度
- 计算：`edit_distance(pred, gold) / max(len(pred), len(gold))`
- 口径：0 表示完全一致，1 表示完全不同
- 局限：对顺序敏感，等价但顺序不同的路径会得高分（差）

## 可靠性层

### 前置条件违反率

- 定义：生成了物理上执行不了的动作的样本占比
- 计算：`count(存在前置条件违反) / count(样本)`
- 口径：违反类型包括「手上已有物体还要拿」「没拿东西就要放」「切片时手上没刀」等
- 局限：依赖状态机规则的准确性，规则写错会误报

**这是本项目最独特的指标。** 它直接量化模型的规划幻觉：生成了一串看起来合理但物理上做不到的动作。SQL 文本生成里没有对应物，因为它不存在物理约束。

### pass^k

- 定义：同一条样本连续跑 k 次都成功，才算通过
- 计算：每条样本跑 k 次，全部成功的占比
- 口径：建议 k=3，成本与信号强度的折中
- 局限：调用量随 k 线性增长

pass@1 与 pass^k 的差值就是模型的不稳定性。τ-bench 用这个指标发现前沿 Agent 单次看着还行，连续八次成功率掉到 25% 以下——单轮成功率高不代表可用。

## 效率层

### 平均动作步数

- 定义：模型输出序列的平均长度，与 gold 长度对比
- 计算：`mean(len(pred))`，另算 `mean(len(pred) - len(gold))` 作为冗余度
- 口径：只统计成功样本，失败样本的长度没有意义
- 局限：短不一定好，漏步骤也会短

### 单条调用成本

- 定义：延迟与 token 消耗
- 计算：平均延迟、P95 延迟、单条平均 token
- 口径：按模型分别统计
- 局限：受网络波动影响，需多次采样

---

## 汇总口径

所有百分比必须带 95% Wilson 置信区间。300 条样本时区间约正负 5 个点，100 条时约正负 9 个点。**点估计单独看没有决策价值**，两个模型的差距小于区间宽度时，不能说谁更好。

分层统计按 7 种官方任务类型，以及 L1 / L2 / L3 三个难度层分别出。只看总分会被简单题稀释。
